# 运行包格式

运行目录属于当前任务，不属于 Skill。目录可以包含真实文章和图片，但不得提交到 Git、复制进 Skill 或归档。

## 推荐结构

```text
<run-dir>/
├── source.md
├── content-package.json
├── media-manifest.json
├── wechat/
│   ├── article-staging.html
│   └── receipt.json
├── xiaohongshu/
│   └── package.json
└── images/
    ├── wechat/
    └── xiaohongshu/
```

## 统一内容包

由 `prepare_content.py` 生成，不手工伪造解析结果。关键字段：

```json
{
  "schema_version": 2,
  "source_sha256": "64 位小写 SHA-256",
  "default_platforms": ["wechat", "xiaohongshu"],
  "title": "原始标题",
  "body_markdown": "完整长文",
  "images": [],
  "layout_instructions": [],
  "publish_options": {"declare_original": true}
}
```

`images[].anchor` 是候选语义位置，不能替代模型对正文和真实页面的判断。

## 媒体清单

所有路径必须是存在文件的绝对路径。`wechat` 按统一内容包的图片 ID 一一映射；`xiaohongshu` 数组顺序就是上传顺序。

```json
{
  "schema_version": 1,
  "source_sha256": "与统一内容包一致",
  "wechat": {
    "image-01": "/absolute/path/wechat-cover.png",
    "image-02": "/absolute/path/wechat-inline.png"
  },
  "xiaohongshu": [
    "/absolute/path/xhs-cover.png",
    "/absolute/path/xhs-card-01.png"
  ]
}
```

清单通过只证明文件和映射有效，不证明图片内容正确。图片仍须视觉复核。

## 小红书发布包

```json
{
  "schema_version": 1,
  "source_sha256": "与统一内容包一致",
  "title": "小红书标题",
  "content": "小红书正文",
  "tags": ["AI", "Agent"],
  "images": ["/absolute/path/xhs-cover.png"],
  "visibility": "公开可见",
  "declare_original": true
}
```

校验器使用当前保守上限：标题不超过 20 个全角字符等效宽度、正文不超过 1000 个字符、标签 1–10 个、图片 1–18 张。页面若显示更严格限制，以真实页面为准并回写发布包后重新校验。

`fingerprint` 由校验器根据规范化包计算。它用于确认版本比较，不得由模型用 `confirmed: true` 自行授权。

## 收据边界

微信草稿收据只保存账号显示名、标题、图片数、源指纹、`media_id` 和 `verified_draft` 状态，不保存 token、secret、正文 HTML 或本地图片路径。小红书页面状态只保留在当前任务观察中，不导出 Cookie 或内部 token。
