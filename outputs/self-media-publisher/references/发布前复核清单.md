# 微信公众号发布前复核清单

每项都必须有当前微信页面中的可观察证据。文章包、脚本输出或模型自述不能单独证明页面已正确呈现。

## 内容完整性

- 标题栏与原稿 H1 一致，正文没有重复一级标题。
- 开头、全部章节、结尾和引用来源均存在，无配图说明或发布指令混入正文。
- 章节顺序正确，正文没有因粘贴、上传或撤销操作丢段或重复。
- 外部链接可用；平台不支持的链接已保留来源名称并整理到文末参考资料。

## 排版与阅读节奏

- 正文约 15–16px、深灰色、1.75–1.9 倍行距，移动端没有明显拥挤。
- 二级和三级标题层级清楚；段落自然，不机械地一句一段。
- 加粗只用于关键判断，没有整段滥用。
- 引用、列表、代码词和分隔线样式一致，技术词保留英文。
- 章节与图片前后有合理留白，没有孤立标题或异常空段。

## 图片与封面

- 图片数量和 ID 映射与文章包一致，顺序正确，无重复上传。
- 每张正文图紧跟对应观点；所有 `review_within_section` 位置已经由 Computer Use 语义复核。
- 图片中文字、数字、箭头和流程方向可读且与正文一致；没有 Logo、人物或用户禁止元素。
- 图片未被拉伸、裁坏或显示为失败占位。
- 封面只用于封面槽位，2.35:1 裁切后标题与核心图形仍在安全区域。

## 发布设置与授权

- 当前草稿身份和公众号身份正确。
- 原创声明已开启；任何额外原创承诺或资格异常已由用户处理。
- 其他发布选项保持后台默认值。
- 用户明确确认发生在当前预览之后，且确认后内容没有变化。

## 发布结果

- 发布按钮只触发一次。
- 平台给出明确成功提示，或已发表列表出现当前标题且草稿状态一致。
- 结果不明时已停止重复点击，并记录需要核对的页面状态。
