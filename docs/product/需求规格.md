# 自媒体双平台发布 Skill 需求规格

修订日期：2026-09-17

## 1. 范围

`self-media-publisher` 服务一个微信公众号账号和一个小红书账号。每次默认同时准备微信公众号长文和小红书图文笔记；用户可以在当次请求中明确只处理其中一个平台。

首版不处理微信公众号多图文合集、转载、视频号、小程序内容，也不处理小红书视频、长文模式、搜索、点赞、收藏、评论、批量互动或无人值守运营。

## 2. 需求

### REQ-001 统一输入与内容包

Skill 必须接受带“配图与插图建议”和当篇排版要求的 Markdown 长文，解析标题、正文、配图任务、语义锚点和发布要求，生成带源文件 SHA-256 的统一内容包。

验收标准：合成样例能解析出一个标题、完整正文、五张配图任务及稳定的语义位置；默认目标平台为 `wechat` 和 `xiaohongshu`。

### REQ-002 双平台内容改编

微信公众号保留完整长文；小红书必须根据同一原始素材重新组织标题、正文、标签和图片叙事，不得机械截断或直接复制整篇公众号正文。

验收标准：小红书发布包包含合规标题、正文、标签、可见范围、原创选项、源指纹和有序图片列表，并能通过确定性校验器。

### REQ-003 全部图片由 AI 生图

微信公众号封面、正文信息图以及小红书封面和内容图全部调用 Codex `imagegen` 生成。不得使用 SVG、HTML/CSS 卡片、Canvas 或其他程序化制图替代。

验收标准：每张图都有独立语义任务和比例要求；模型检查主题、比例、中文、数字、流程方向和信息完整性，未通过检查的图片不得进入草稿。

### REQ-004 微信公众号 API 草稿

微信公众号使用已验证的官方 API 路线：获取 access token、上传封面和正文图片、创建普通图文草稿，并读取草稿关键字段进行回读核验。API 实现沿用 `jiji262/wechat-publisher` 已验证的接口边界和移动端兼容经验，但代码纳入本 Skill 后必须保持单账号、最小权限和可测试边界。

验收标准：离线测试证明请求方法、接口路径、正文图片替换、封面上传、草稿负载和错误处理；真实验收需要单独授权，且终点为草稿箱，不自动群发。

### REQ-005 微信移动端兼容排版

微信公众号正文使用微信兼容内联样式，标题不在正文重复，无序列表不得出现手机端项目符号与文字分离的布局。

验收标准：渲染测试覆盖标题、段落、引用、代码、链接、无序列表、图片位置和移动端安全项目符号；草稿回读不得包含本地文件路径或配图指令。

### REQ-006 小红书安全填充

小红书采用可见 Chrome 和 Codex Computer Use 操作官方创作者页面。流程必须先填充标题、正文、标签、图片和发布选项，保存草稿或停在预览，再由 Computer Use 从真实页面复核。

验收标准：Skill 不调用私有接口，不读取 Cookie 或 `xsec_token`，不运行 Headless 浏览器，不修改浏览器指纹，不使用 CDP、closed Shadow DOM 穿透或脚本事件绕过页面。

### REQ-007 登录与平台验证

扫码、验证码、短信验证、实名认证、安全确认、原创资格异常和账号风险提示必须交由用户处理。

验收标准：出现上述挑战时停止，不自动重试、不代填、不绕过。

### REQ-008 双平台预览与确认

默认同时准备两个平台，但公众号与小红书拥有独立内容指纹、草稿身份和确认状态。可以在一条消息中同时确认两个平台，但确认必须明确列出目标平台和对应内容版本。

验收标准：内容、图片、封面、标签或发布设置变化后，对应平台旧确认失效；未确认的平台不得发布。

### REQ-009 防重复与真实结果

所有外部写入必须以平台返回值或页面状态为证据。响应不明时先读取草稿、发布记录或页面结果，不得连续重复提交。

验收标准：确定性测试覆盖微信 API 错误和重复调用保护规则；浏览器流程明确规定状态核对与停止条件。

### REQ-010 凭证与运行数据隔离

AppID、AppSecret、access token、Cookie、验证码、文章和生成图片不得进入 Git、Skill 安装包或长期日志。微信公众号配置必须来自运行目录之外的权限受限文件。

验收标准：结构测试扫描候选包，不包含真实用户原稿、凭证配置、token 缓存或运行生成物。

## 3. 非功能要求

- 所有开发、审查和验证由主 Agent 完成，不使用子代理。
- 使用一个 Codex 原生 Agent Loop；不引入 LangGraph、Deep Agents 或常驻 MCP 服务。
- 确定性脚本只负责可客观验证的解析、校验、API 请求和制品生成；内容改编、图片质量和页面纠偏由模型负责。
- 小红书使用固定单账号、固定可见 Chrome Profile、稳定网络出口和正常人工发布节奏。
- 浏览器安全策略拒绝任何动作时立即停止；不得换用 CDP、脚本注入或其他自动化绕过。
- 离线测试不得访问真实公众号或小红书账号。
