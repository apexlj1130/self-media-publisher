# 微信公众号文章发布 Skill 需求规格

修订日期：2026-09-16

## 范围

首版仅支持一个微信公众号账号的普通单篇图文文章。多图文合集、转载、视频号和小程序内容不在首版范围内。

## 需求

### REQ-001 输入解析

Skill 必须接受 Markdown 长文。首个一级标题作为公众号标题；正文位于文章开头至“配图与插图建议”之间；配图章节提供编号、位置、作用、尺寸和生图提示词；末尾“给 Codex 的发布与排版要求”覆盖默认排版规则。

验收标准：提供的样例能解析出一个标题、完整正文、五张配图任务及每张图的语义插入位置。

### REQ-002 AI 配图

封面和正文信息图全部使用 AI 生图工具生成。每张图必须根据独立提示词生成，并检查比例、主题一致性、中文可读性和关键信息完整性。

验收标准：任何未通过视觉检查的图片不得进入最终草稿；无法稳定生成合格图片时必须停下并说明问题。

### REQ-003 文章排版

Skill 必须应用专业、克制、适合技术长文的默认样式，并允许当篇排版要求覆盖默认值。脚本只提供候选样式和语义锚点，Computer Use 必须依据微信编辑器中的实际内容进行复核和纠偏。

验收标准：标题层级、段落节奏、重点、引用、列表、技术词、图片位置和章节留白均符合功能设计。

### REQ-004 登录与验证

Skill 必须复用用户当前 Chrome 配置中的微信公众号登录状态。遇到扫码、验证码、短信验证、安全确认或账号选择时，必须暂停并通知用户接管。

验收标准：Skill 不读取、保存或代填密码，也不绕过平台验证。

### REQ-005 草稿与预览

完成排版和图片插入后，Skill 必须从头到尾复核，保存草稿并停留在可供用户检查的预览状态。

验收标准：用户确认前不得进入正式发布动作。

### REQ-006 原创声明与发布

默认勾选原创声明，其他发布选项沿用公众号后台默认设置。原创承诺、资格异常或平台额外确认出现时必须暂停交给用户处理。

验收标准：只有收到针对当前文章和当前草稿的明确“确认发布”后，Skill 才能执行最终复核并发布；确认后内容发生变化必须重新确认。

### REQ-007 防重复发布

发布失败或页面状态不明时，Skill 必须先核对后台状态，不得连续重复点击发布。

验收标准：不因超时、刷新或不确定响应造成重复发布。

## 非功能要求

- 浏览器操作依据可见文本、可访问性信息和页面语义，不依赖固定屏幕坐标。
- 运行状态仅保留恢复任务所需的信息：当前文章、图片清单、已完成步骤、草稿标识及确认状态。
- 生成内容与账号信息不得写入 Skill 包或长期日志。
- 微信页面结构变化时，应优先重新观察页面并调整，而不是盲点坐标或循环重试。
