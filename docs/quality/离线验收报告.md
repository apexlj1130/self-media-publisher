## 缺陷关闭：真实文章进入 Skill 包

- 症状：初版候选包和安装目录包含逐字节复制的用户文章测试夹具。
- 影响：违反“文章内容不进入 Skill 安装目录”的隐私与状态边界，且会使远程 Git 历史携带原稿。
- 第一失败边界：测试数据准备步骤把真实附件复制到了可交付 Skill 目录。
- 直接触发：归档命令正确地打包了整个 Skill 目录。
- 根因：实施计划混淆了“真实样例验收数据”和“可发布单元测试夹具”的生命周期与所有者。
- 既有测试遗漏原因：结构测试只检查文件存在和链接，没有检查用户原稿摘要是否进入制品。
- 同类扫描：候选包、旧归档和安装副本均检查；只发现该测试夹具一个匹配项。
- RED 证据：新增隐私测试后，明确报告 `tests/fixtures/示例文章.md` 与原稿 SHA-256 相同。
- 修复：测试夹具替换为明确标注的合成文章；真实附件只在临时目录做一次本地验收。
- 回归：9/9 测试通过，候选包与安装目录均不含原始文章摘要。
- 历史处理：远程 Git 只会推送 squash 后的干净 `main`；包含旧夹具的临时功能分支不会推送，并在本地收口后删除。
